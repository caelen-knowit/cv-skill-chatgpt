# CV Match Coach – command cheat sheet

Type these in the chat. You can write them in English or Swedish, and small typos are fine.
Always upload the CV first (Word, PDF, scan, CV-system export or pasted text), plus the client request when matching. The skill starts by showing what it read from the file. Check it quickly.

## Typical workflow

| Step | Type this | You get |
|---|---|---|
| 1 | *(upload CV + paste request)* `Match this CV to this assignment` | Match report with score, gaps and open questions |
| 2 | `1: yes, 18 months. 2: he led the team. 3: ...` | The answers are stored, and scores are updated where answers change them |
| 3 | `Experience check` | Proven time per requirement (years and months, last used, role) |
| 4 | `Write the CV` (or `Write the CV, light` / `heavy`) | Tailored CV, list of changes, source check, items left out |
| 5 | `Pitch` | Short email text to the client |
| 6 | `Word file` | .docx of the tailored CV |

## Experience questions

| Type this | Example | You get |
|---|---|---|
| `Experience check: <skills>` | `Experience check: Kafka, Azure, Terraform, team lead` | Table: proven time, last used, # assignments, role, evidence, confidence |
| `Experience check` | *(after a request is uploaded)* | Same table for all the request's requirements, plus "meets requirement?" yes/no/unclear |
| `How many years of <X>?` | `How many years of Java?` | One-skill answer with the calculation shown |
| `Does <name> have <X> years of <Y>?` | `Does Anna have 3+ years of React?` | Yes / No / Unclear + why + question if unclear |
| `Skill profile` | | Full inventory of all skills sorted by proven experience |
| `When did <name> last use <X>?` | `When did Erik last use AWS?` | Last assignment + date |
| `Who has <X>?` | *(several CVs uploaded)* `Who has most Azure experience?` | Ranked list across CVs |

Skills can also be roles, methods or industries: `Experience check: Scrum Master, banking, public sector, architect role`.

## Matching and quality

| Type this | You get |
|---|---|
| `Quick check` | Score, 3 strengths, 3 gaps (max 10 lines) |
| `Compare these CVs` | Ranked table for one request |
| `Review this CV` | General quality feedback without a request |
| `What's missing for this assignment?` | Gaps only, with questions to the consultant |
| `Interview prep` | Likely client questions and weak spots to prepare |
| `Anonymise` | Tailored CV without the consultant's name (and without employer names if you ask) |

## Improving a CV (with or without a client request)

| Type this | You get |
|---|---|
| `Suggest changes` | Numbered table: section, current text, suggested text, why, priority. Nothing is rewritten yet. |
| `apply 1, 3, 5` / `apply all` / `apply all High` | The updated CV with only those changes |
| `reject 2` / `change 3: <your text>` | Adjusts the suggestion list |
| `Improve CV: light` | Polish: language, consistency, buzzwords removed. Structure and voice kept. |
| `Improve CV: medium` | Plus a new profile, reordered skills, assignments restructured, old work shortened |
| `Improve CV: heavy` | Full rewrite in house style. Old work grouped, skills trimmed. |
| `Lighter` / `Heavier` | Redo one level down or up |
| `Show diff` | Before/after table per section |
| `Grade this CV` | Quality score on 8 criteria with fixes |
| `Prepare for library` | Strict anonymisation and grade, for the example library (needs human approval) |

No level adds facts. Heavier levels usually come with more questions first.

## Adjusting the CV

| Type this | Example |
|---|---|
| `Shorter` / `Max <n> pages` | `Max 2 pages` |
| `In Swedish` / `In English` | |
| `Focus more on <X>` | `Focus more on the leadership experience` |
| `Rewrite the profile` | `Rewrite the profile, less technical, the reader is a manager` |
| `Add: <fact>` | `Add: Erik passed AZ-104 in March 2025` *(the skill takes this as a confirmed fact from you)* |
| `Remove <X>` | `Remove the assignments before 2015` |
| `Show sources` | Source check table again |
| `Cinode` | Changed texts field by field, ready to paste back into Cinode |
| `Word file` / `PDF file` | Download (structure follows the uploaded CV) |

## Good to know
- Swedish commands work too (see [kommandon.md](kommandon.md)).
- A **Cinode export** works as both the CV and the template. Make the final layout with Cinode's export.
- The skill **asks rather than guesses**. "Unclear" in a table means the CV doesn't prove it. Answer the question and it will be updated.
- **"Listed only"** means the skill is in the skills list but not in any dated assignment, so it counts as 0 proven months.
- Ranges like **"8–19 months"** mean the CV only has years and no months. Give the exact months to get a single number.
- You are responsible for what you send. Spot-check the source table before sending.
