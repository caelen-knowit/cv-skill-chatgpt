# CV Match Coach – kommandon (fusklapp)

Skriv kommandona i chatten på svenska eller engelska, och små stavfel gör inget.
Ladda först upp CV:t: Cinode-export (Word/PDF), annan fil eller inklistrad text. När du vill matcha klistrar du också in kundförfrågan.
Skillen börjar alltid med att visa vad den har läst ur filen. Kontrollera det snabbt.

## Vanligt arbetsflöde

**Börja varje ärende med `Starta CV Match Coach`.** Den guidar dig steg för steg. Du behöver inte komma ihåg något av detta. Varje svar slutar med en meny (A, B, C, D), och du svarar med en bokstav. Skriv `hjälp` för att se startmenyn. Kommandona nedan är genvägar.


| Steg | Skriv | Du får |
|---|---|---|
| 1 | *(CV + förfrågan)* `Matcha CV:t mot uppdraget` | Matchningsrapport: poäng, luckor och numrerade frågor |
| 2 | `1: ja, 18 månader. 2: hon ledde teamet.` | Svaren används och poängen uppdateras |
| 3 | `Erfarenhetskoll` | Bevisad tid per krav (år/månader, senast använt, roll) |
| 4 | `Föreslå ändringar` **eller** `Skriv CV:t` (lätt/mellan/mycket) | Ändringslista eller anpassat CV, med en källkontroll |
| 5 | `Cinode` | Texterna fält för fält, klara att klistra in i Cinode |
| 6 | `Pitch` / `Word-fil` / `PDF-fil` | Mejltext till kunden / fil. Word-filen får exakt samma typsnitt, storlekar och layout som originalet om du laddade upp en Word-fil. |

## Erfarenhet

| Skriv | Exempel |
|---|---|
| `Erfarenhetskoll: <kompetenser>` | `Erfarenhetskoll: Kafka, Azure, teamledare, bank` |
| `Hur många år <X>?` | `Hur många år Java?` |
| `Har hon/han <X> år <Y>?` | `Har Anna 3+ år React?` |
| `Kompetensprofil` | Alla kompetenser sorterade efter bevisad erfarenhet |
| `Vem har mest <X>?` *(flera CV:n)* | `Vem har mest Azure?` |

## Förbättra CV (med eller utan förfrågan)

| Skriv | Du får |
|---|---|
| `Föreslå ändringar` | Numrerad tabell: nuvarande text, förslag, varför och prioritet |
| `verkställ 1, 3, 5` / `verkställ alla Hög` / `avvisa 2` | Uppdaterat CV med just de ändringarna |
| `Förbättra CV: lätt` | Språk, konsekvens och modeord. Struktur och ton behålls. |
| `Förbättra CV: mellan` | Dessutom ny presentation, ny ordning på kompetenserna och omskrivna uppdrag |
| `Förbättra CV: mycket` | Helt omskrivet i husstil |
| `Lättare` / `Mer` / `Visa skillnader` | Gör om en nivå ner eller upp / visar före och efter |
| `Betygsätt CV:t` | Kvalitetspoäng på 8 kriterier med förbättringsförslag |
| `Anonymisera` | CV utan namn (och utan kundnamn om du ber om det) |

## Bra att veta
- Skillen **frågar hellre än gissar**. Det som inte kan bekräftas lämnas utanför CV:t.
- **"Endast listad"** betyder att kompetensen står i listan men inte syns i något daterat uppdrag. Den räknas som 0 bevisade månader.
- **Cinode-export** fungerar som både CV och mall. Den slutliga layouten tar du fram med Cinodes export.
- Du ansvarar för det du skickar. Stickprova källkontrollen innan du skickar något.
