# Test script – first real test with your own CV (≈45 min)

Purpose: check the skill end to end, using a CV you know by heart. You will spot every invented or wrong detail immediately.

## Before you start
- Your CV exported from Cinode, **Word (.docx)** if possible, otherwise PDF.
- A client request: a real one, or a public job ad / broker request that fits you, and one that does **not** fit you.
- The skill uploaded (see the [README](../README.md)), or the [Project setup](setup-alternatives.md).
- A notes document where you record: test #, what went wrong, and a copy of the bad output.

## Run these in order (new chat)

| # | Type / do | Check | OK? |
|---|---|---|---|
| 1 | Attach the CV. `Skill profile` | Extraction summary: is the number of assignments and the date range right? Is anything unreadable flagged? Are proven months correct for 3 skills you know? Are overlaps counted once? | |
| 2 | `Experience check: <3 skills you have>, <1 skill you only list>, <1 skill you don't have>` | "Listed only" gives 0 months. A missing skill gives "Not found". The calculation is shown. | |
| 3 | Paste the **matching** request. `Match this CV to this assignment` | Is the score reasonable? Do the requirements have the right MUST/SHOULD labels? Are the questions specific and sensible? | |
| 4 | Answer only *some* of the questions. `Write the CV` | It should re-ask the unanswered ones and **not** write yet | |
| 5 | `write it anyway` | Unconfirmed items appear under "Left out". Read every line: is anything invented, inflated ("led" vs "took part"), or copied from the example CV? | |
| 6 | `Show diff` / check the source table | Spot-check 5 claims against your real CV | |
| 7 | `Suggest changes` then `apply 1, 3` | Only changes 1 and 3 are applied | |
| 8 | `Improve CV: light` then `Heavier` | Light keeps your voice and structure. Heavier restructures. Neither adds facts. | |
| 9 | `Cinode` | Field-by-field texts, only changed fields, ready to paste | |
| 10 | `Word file` | The file opens, and its structure follows your Cinode CV | |
| 11 | New chat: the same CV + the **non-matching** request. `Quick check` | Weak match / No-go, and the missing MUST is named | |
| 12 | Repeat 3–5 in **the other language** (Swedish ↔ English), e.g. `Matcha CV:t mot uppdraget` | CV text stays in the CV's language. Swedish commands work. | |
| 13 | `Grade this CV` | Is every score backed by a quote from your CV? | |
| 14 | `Pitch` | Would you send it as-is? Is it free of hype? | |

## Score the test
- **Any invented fact = stop.** Copy the exact output and send it to me. That's the most important bug class.
- Wrong numbers (months/years) → send the CV dates and the output.
- Bad tone or wording → copy the sentences. They go into the banned list or an example.
- Formatting problems in Word → expected to some degree. Use `Cinode` for paste-back instead.

## Privacy note
It's your own CV, so testing is fine. Still, don't paste other people's CVs until IT/DPO has confirmed the setup ([admin guide](admin-guide.md), section 3).
