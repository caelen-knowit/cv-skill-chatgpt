# Example library

Approved example CVs that show the house style. STYLE ONLY: the skill must never copy facts from these files.

- Start: `example-fictional-backend-developer.md` (fictional, shows the style).
- ⚠️ The GitHub repo may be public. Keep real examples, even anonymised ones, OUT of the public repo. Add them to the zip only on a company drive, or keep a private fork.
- Grow: add anonymised real examples ONLY through the approval process in `references/cv-quality-rubric.md` (score + real-world signal + consent + two-person review).
- Keep max ~2 per role type and language. Name files `example-<role>-<lang>.md` or `before-after-<role>-<lang>.md`.
- Remove the fictional example once 2+ real examples exist for that role type.
